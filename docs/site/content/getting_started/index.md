# Getting Started

This section introduces vm-harness and gets you from a clean checkout to a
booted VM running its first in-guest assertion.

- [Overview and concepts](/getting_started/overview-and-concepts) — what
  vm-harness is, the `VmBackend` abstraction, the per-gate reset performance
  contract, and the three-tier ownership model that explains what belongs in
  vm-harness and what belongs in your own code.
- [Getting started](/getting_started/getting-started) — enter the dev
  shell, build the CLI, see which backends your host can drive, and bring a VM
  up to run your first assertion (from the CLI or the library).
